# Employee Management System

This is a simple Python-based Employee Management System using **SQLite3** for local database storage.

### 🚀 Features
- Add Employee
- View All Employees
- Search Employee by ID
- Delete Employee
- CLI (Command Line Interface) based application

### 🛠 Technologies Used
- Python
- SQLite3 Database

python employee_management.py
